# 🎧 YouTube Playlist to MP3 Downloader

A full-stack web application built using Flask that allows users to download entire YouTube playlists as MP3 files with a simple and clean interface.

---

## 🚀 Features

- 🔗 Download full YouTube playlists
- 🎵 Convert videos to MP3 format automatically
- 📥 Download individual songs
- 📦 Download all songs as ZIP file
- 📃 Displays song names after download
- 💅 Modern Glassmorphism UI
- ⚡ Fast and lightweight

---

## 🛠 Tech Stack

- **Backend:** Python (Flask)
- **Frontend:** HTML, CSS (Glass UI)
- **Library:** yt-dlp
- **Conversion:** FFmpeg
- **Deployment Ready:** Gunicorn
